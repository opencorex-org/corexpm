# TypeScript packages

This area is reserved for versioned JavaScript/TypeScript integration packages,
not the native package-manager core.

Planned packages include:

- `corex-sdk` — programmatic command and metadata APIs;
- `corex-plugin-sdk` — future versioned sandbox plugin types;
- `corex-node-loader` — future Corex Virtual Node loader; and
- `create-corex` — project bootstrap UX if demand warrants it.

Each package will be added only with an owner, public API proposal, tests, and
release plan. CorexPM must not require Node.js to run its native CLI.
