# Requests for Comments

Use an RFC for lockfile/config formats, resolver semantics, CLI compatibility,
security capabilities, plugin APIs, or changes spanning several components.

1. Copy [0000-template.md](0000-template.md) to a descriptive branch filename.
2. Open a pull request with status `proposed`.
3. Gather implementation, compatibility, operations, and security feedback.
4. Record the outcome and merge the document before relying on the decision.

An accepted RFC describes behavior; it does not imply implementation is done.
